
# 📰 Actu-Info — Le blog des nouvelles technologies

> Blog d'actualité et de conseils en informatique : sécurité, Windows, Linux, IA et Web.

---

## 📖 À propos

**Actu-Info** est un blog dédié aux nouvelles technologies. Il publie régulièrement des articles pratiques, des conseils et des actualités autour de l'informatique.

Le site couvre **5 grandes thématiques** :

- 🔒 **Sécurité** — phishing, VPN, protection des données
- 🪟 **Windows** — astuces, dépannage, optimisation
- 🐧 **Linux** — commandes, configuration, outils
- 🤖 **IA** — ChatGPT, prompts, outils d'intelligence artificielle
- 🌐 **Web** — développement, navigateurs, technologies web

L'objectif : rendre la tech accessible et utile au quotidien.

---

## ✨ Fonctionnalités

- 🏠 **Accueil** — page principale avec les derniers articles
- 📂 **Navigation par catégorie** — Sécurité, Windows, Linux, IA, Web
- 📰 **Derniers articles** — liste chronologique des publications
- 🎨 **Design responsive** — adapté mobile / tablette / desktop
- ⚡ **Site statique** — chargement rapide, pas de backend
